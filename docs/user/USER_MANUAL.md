# Nolia 使用手册

Nolia 是一款跨平台本地优先 Markdown 知识工作台。用户正文保存在自己选择的工作区目录中；`.nolia/` 目录只保存索引、快照、缓存和应用元数据。

## 快速开始

1. 安装适合当前系统的 Nolia 包。macOS 使用 `.dmg` / `.zip`，Windows 使用安装器或 `.zip`，Linux 使用 AppImage / deb。
2. 在首页选择「打开工作区」或「创建工作区」。普通可写目录会先显示初始化确认，确认后才创建 `.nolia`。
3. 从工作区主页新建笔记、今日笔记、快速捕获或从模板新建，也可以直接打开已有 Markdown 文件。
4. 使用顶部工具栏在「编辑」「Markdown 源码」「分屏预览」之间切换。
5. 通过一级导航进入「文件」「发现」「AI」；当前文档的目录、属性、关系和历史位于右侧检查器。

## 安装与数据

- 支持 macOS、Windows 和 Linux 桌面环境。
- 正式发布包应优先选择与当前系统和架构匹配的产物。
- 升级或卸载应用不会主动迁移或删除工作区文件。
- 如需清理全局状态，可删除当前系统的 Nolia 应用数据目录。
- 推荐把工作区纳入 Time Machine、文件历史记录、Git 或云盘备份，但同步目录可能产生外部修改冲突。

## 主界面

- 一级导航：固定为文件、发现和 AI，设置位于底部。
- 侧边栏：展示当前视图列表、搜索结果或文件树。
- 编辑区：编辑 Markdown、JSON、TXT，或预览图片、PDF、音视频等资源。
- 右侧检查器：显示目录、属性、关系和历史；1180px 以下通过顶部按钮以抽屉打开，点击遮罩或按 `Escape` 关闭。
- 状态栏：显示保存状态、字数、行数和当前编辑模式。

## 文件与格式

文件树支持新建、打开、重命名、删除、拖拽移动、文件夹展开收起和右键菜单。

内置处理规则：

- Markdown：`.md`、`.markdown`、`.mdown`、`.mkd`。
- JSON：`.json`，支持校验、格式化、压缩和排序键。
- 文本：`.txt`、`.log`、`.csv`、`.yaml`、`.yml`、`.toml`、`.xml`、`.html`、`.js`、`.ts`、`.tsx` 等。
- 资源预览：图片、PDF、音频、视频、压缩包和未知二进制文件。
- 插件可扩展新的文件编辑器或预览器。

## Markdown 编辑

编辑模式提供所见即所得体验，源码模式使用 CodeMirror，分屏模式并排显示源码和预览。

常用语法：

```md
# 标题
**加粗** *斜体* ~~删除线~~ `行内代码`
- 无序列表
1. 有序列表
- [ ] 任务项
> 引用
[链接](https://example.com)
![图片说明](https://example.com/image.png)
```

支持 GFM 表格、脚注、数学公式、Mermaid、HTML 块、代码块和扩展块。复杂语法在编辑模式下会尽量显示为渲染结果；选中或点击后可回到原始 Markdown 源码进行修改，失焦后重新渲染。

代码块示例：

````md
```ts
console.log("Nolia");
```
````

公式示例：

```md
$E = mc^2$

$$
\int_0^1 x^2 dx
$$
```

表格支持插入、行列调整、对齐和源码编辑。发布前应使用 `examples/markdown-syntax-test.md` 做人工回归。

## 搜索、收藏与反向链接

- 「发现」统一搜索标题、正文、路径、标签、属性和任务项，支持精确与混合模式；语义索引不可用时会明确降级到精确搜索。
- 搜索可以保存、再次运行或删除。标签支持计数、筛选和带文件清单的重命名预览。
- 最近浏览和最近编辑会根据工作区记录恢复。
- 收藏用于固定常用文档。
- 关系检查器显示出链、反向链接和未链接提及，并可预览“转为链接”。局部关系图支持 1/2 层、最多 60 个节点和键盘节点列表。

## 捕获、Daily Note 与模板

- 快速捕获默认追加到 `Inbox/YYYY-MM.md`。
- 今日笔记默认创建 `Daily/YYYY-MM-DD.md`。
- 模板默认读取 `Templates/`，支持 `date`、`time`、`title` 和 `workspace`，不执行 JavaScript。
- 目录和日期命名模式可在「设置 -> 文件与附件」修改。绝对路径、路径穿越和跨平台非法文件名会回退为安全默认值。

## 属性、标签与双链

- 属性检查器支持 string、number、boolean、date、string list 和 tags。写入前校验 base hash 并创建历史快照。
- YAML 无效时不能进行可视属性写入，应先切到源码修复错误。
- 在源码或分屏编辑器键入 `[[` 会显示按文档标题和路径匹配的候选；无匹配时可以直接创建新的 Markdown 笔记。
- 重命名 Markdown 文件前会列出相对链接和可唯一解析 wikilink 的修改范围，确认后在一个可回滚操作中更新。

## 多文档与恢复

- Tab 会保存路径、模式、最近使用顺序和关闭栈。启动最多恢复最近 8 个文档，持久引用最多 20 个。
- `Command/Ctrl+Shift+T` 重新打开最近关闭的文档。
- 未保存内容写入草稿；磁盘 hash 改变时进入冲突状态，不会静默覆盖外部修改。

## Finder 与单文件编辑

- 从 Finder 双击、右键“打开方式”、拖到 Dock，或使用 `Command/Ctrl+O` 打开的 Markdown 会作为外部标签加入当前窗口，不会暂停或替换工作区。
- 外部标签支持编辑、源码、分屏、目录、frontmatter 属性、查找、AI、保存、另存为，以及 Markdown/HTML/PDF 导出。
- 外部文件的恢复草稿保存在 Nolia 用户数据目录，不会在源文件旁创建 `.nolia`。保存时保留 UTF-8 BOM 和原始 CRLF/LF；非 UTF-8 文件以只读方式打开。
- 文件被其他应用修改时，Nolia 会阻止关闭或切换并显示版本比较，可选择继续编辑、重新加载磁盘版本、另存副本或确认覆盖。文件被删除或移动后，当前正文仍会保留。
- 相对 Markdown 链接在新的外部标签中打开；插入图片默认写入文档旁的 `<文件名>.assets` 并生成相对链接。
- “打开所在文件夹”需要明确确认，只创建当前应用会话内的临时 Markdown 文件树，不创建 `.nolia`、数据库、语义索引、关系图或全工作区 AI。可再选择“初始化为工作区”获得完整能力。
- 最近文件与最近工作区分开记录。外部文件不提供工作区历史、关系图和标签统计。

## 设置与快捷键

设置入口：macOS 使用 `Command+,` 或菜单「Nolia -> 设置」；Windows/Linux 使用菜单中的设置入口。

常用快捷键：

| 快捷键 | 功能 |
| --- | --- |
| `Command/Ctrl+N` | 新建文档 |
| `Command/Ctrl+O` | 打开 Markdown 文件 |
| `Command/Ctrl+Shift+O` | 打开工作区 |
| `Command/Ctrl+S` | 保存当前文档 |
| `Command/Ctrl+W` | 关闭当前标签 |
| `Command/Ctrl+Shift+W` | 关闭窗口 |
| `Command/Ctrl+K` | 命令面板 |
| `Command/Ctrl+F` | 当前编辑器搜索 |
| `Command/Ctrl+B` | 加粗 |
| `Command/Ctrl+I` | 斜体 |
| `Command/Ctrl+Shift+E` | 导出 |
| `Command/Ctrl+Shift+T` | 重新打开最近关闭的文档 |

设置项包括主题、编辑模式、编辑区宽度、字体大小、专注模式和插件管理。

## 插件

外部插件目录：

```text
macOS:   ~/Library/Application Support/Nolia/plugins/<pluginId>/
Windows: %APPDATA%\Nolia\plugins\<pluginId>\
Linux:   ~/.config/Nolia/plugins/<pluginId>/
```

插件默认需要在设置中接受权限并手动启用。目标版本只运行隔离的 Plugin API v3；v2 仅展示迁移诊断。权限变化后必须重新确认。开发说明见 [插件开发指南](../plugins/PLUGIN_DEVELOPMENT.md)。

## 故障排查

- 应用无法打开：确认系统安全设置、架构匹配、文件权限和应用完整性。
- 最近工作区无法打开：确认目录仍存在且当前用户有读写权限。
- 文件树不刷新：点击刷新、重启应用，或确认外部同步工具未锁定文件。
- 自动保存异常：检查状态栏提示，避免同时用其他编辑器修改同一文件。
- Markdown 复杂语法无法编辑：切换到源码模式，或选中语法块后编辑原始 Markdown。
- JSON 格式化失败：先根据诊断修复语法错误。
- 插件不显示：确认插件目录、`plugin.json`、权限确认和安全模式状态。
- 资源无法预览：确认文件未损坏，未知格式会回退到通用资源视图。
